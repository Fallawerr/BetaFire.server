Server rules

  1. Griefing and stealing are prohibited.
  2. The use of cheats and any modifications that provide an advantage is prohibited.
  3. Respect other players, don't be toxic in chat
  4. Don't build huge farms that put a lot of strain on the server (redstone lag, etc.)
  5. Don't spoil the landscape without reason (lava/water everywhere, clear-cutting of forests, etc.)
  6. Build away from spawn and other people's buildings (at least 300-500 blocks)
  7. If you accidentally break something, fix it or report it on Discord (in development)

Violation of the rules → permanent ban with no possibility of unbanning.

All actions are logged by CoreProtect, so there are no excuses like "it wasn't me."
