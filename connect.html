How to install Beta 1.7.3

Option 1 (the simplest)

Download betacraft launcher
Betacraft Launcher

Option 2 (official launcher)

  1. Open the official Minecraft Launcher
  2. Create a new installation → select version 1.7.3 (If not, enable old beta versions in the settings)
  3. Launch it and log in to your licensed account.
  4. Add server: play.server-is-not-started.com

Option 3 (MultiMC / Prism Launcher)

Create a new profile with version 1.7.3 and connect as usual.

After successfully downloading the version and adding the server, wait until you are added to the whitelist.

To get to the server, please complete the form.
